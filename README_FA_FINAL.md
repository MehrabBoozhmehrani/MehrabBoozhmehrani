# راهنمای نسخه نهایی پورتفولیوی مهراب بوژمهرانی

## اجرا
```bash
pnpm install
pnpm dev
```

برای ساخت نسخه انتشار:
```bash
pnpm build
pnpm preview
```

## زبان‌ها
- زبان پیش‌فرض فارسی است.
- دکمه EN/فا در نوار بالا، زبان را بین دو نسخه فارسی و انگلیسی تغییر می‌دهد.
- متن‌های محتوایی فارسی و انگلیسی در ساختار `fa` و `en` جدا هستند.

## پنل مدیریت
- از دکمه «مدیریت / Admin» در نوار بالا وارد پنل شوید.
- محتوای سایت پس از راه‌اندازی Supabase در دیتابیس مرکزی ذخیره می‌شود؛ فقط مدیر مجاز می‌تواند آن را تغییر دهد. راهنمای کامل در `README_ADMIN_FA.md` است.
- تمام اطلاعات در قالب JSON قابل ویرایش است؛ برای تغییر قیمت خدمات، مقدار `services[].price` را تغییر دهید.
- برای انتقال اطلاعات به دستگاه دیگر، از Export JSON و سپس Import JSON استفاده کنید.

**محدودیت مهم استقرار:** این پروژه در وضعیت فعلی یک سایت فرانت‌اند است و پنل مدیریت تغییرات را فقط در مرورگر همان دستگاه ذخیره می‌کند. برای اینکه ویرایش قیمت یا محتوا روی سایت عمومی و برای همه بازدیدکنندگان اعمال شود، باید یک بک‌اند با پایگاه داده و ورود امن سمت سرور (برای مثال Supabase یا Firebase) متصل شود. پنل سمت مرورگر به‌تنهایی احراز هویت امن یا انتشار عمومی ایجاد نمی‌کند؛ بنابراین پیش از استفاده عمومی از پنل، این اتصال لازم است.

## مدارک
هفت فایل PDF ارسالی در مسیر `public/certificates/` قرار گرفته‌اند و در بخش مدارک قابل مشاهده‌اند. عنوان‌ها و سرفصل‌ها از متن قابل خواندن روی گواهی‌ها استخراج شده‌اند.

## رزومه
رزومه از اطلاعات تأییدشده موجود در پروژه و مدارک ارسالی ساخته می‌شود. اطلاعات تحصیلی رسمی، تاریخ اشتغال مستقل، سطح زبان یا سوابقی که در فایل‌ها وجود نداشته‌اند، به‌صورت حدسی اضافه نشده‌اند.

## کارایی
نسخه اصلی صفحه از طراحی سبک و بدون صحنه WebGL، انیمیشن‌های سنگین و اسکرول نرم اجباری استفاده می‌کند تا بارگذاری و تعامل در موبایل و دسکتاپ روان‌تر باشد.
